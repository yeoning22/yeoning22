## <img src="https://github.com/user-attachments/assets/649a827f-4a18-492e-b930-c60563625d85" /> 소개

- 작은 기능이라도 구현해보며 **원리를 이해하려** 합니다.
- 다양한 분야의 기술을 직접 다뤄보며 **기본기를 쌓고** 있습니다.  
- **특정 분야**에 고정되지 않고, 여러 **새로운 기술**을 가볍게 시도합니다.  
- 1인 또는 소규모 단위로 프로젝트를 진행하며, **과정을 기록**하고자 합니다.  
- 단·장기간 개발이 어려울 때에도, 언제든 다시 시작할 수 있도록 **계획과 과정을 문서화**하고 있습니다.
